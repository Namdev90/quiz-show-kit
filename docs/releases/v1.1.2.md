# Quiz Show Kit v1.1.2

This targeted BioVista update completes the 40 inherited evidence reviews and adds 160 concise, original option rationales. All 41 cards now have inspected-source records dated 15 October 2026, with exact sections and support notes. No stem, option, key, overall explanation, score rule, question ID or pair changes were required. Historical source dates and original citation identities remain intact; corroborating references are appended.

M23's pre-reveal accessible label now describes the symbol's geometry without naming its answer. The original artwork and stable media mapping are preserved. All 13 inherited heuristic warnings have explicit dispositions: one label correction and twelve reviewed wording, numerical-form or internal-identifier candidates. The heuristics remain visible rather than being silenced. The evidence ledger and [review notes](https://github.com/Namdev90/quiz-show-kit/blob/v1.1.2/examples/biovista/EVIDENCE_REVIEW.md) disclose shared teaching, uncalibrated pair-demand differences and limited reserve coverage.

Opening source or option-rationale details with Enter/Space now preserves the native expansion action and stays on the revealed question. The general next-question shortcut no longer intercepts those summaries.

The preservation guard allows only reviewed supplemental metadata and explicitly recorded accessible-label corrections. Exact question receipts cannot authorize changes to archived educational content, IDs, pair order, original citation titles/URLs or normalized scoring/timing rules. Matching offline HTML, editable DOCX, reusable settings and quality companions are regenerated together. Builds themselves do not fetch sources or establish factual truth.

The enriched bank has a new configuration profile, so its local checkpoint namespace is separate. Continue an ongoing event in its original saved/released file; a resume copy from an earlier profile is not silently migrated into this update.

v1.1.0 and v1.1.1 remain unchanged. GitHub release downloads remain the delivery route; Pages stays disabled. MCQ-only operation, offline gameplay, the fixed Apex showcase, ordinary configurable quizzes and all rejected/unresolved feature decisions are preserved. See [actual verification and platform limits](https://github.com/Namdev90/quiz-show-kit/blob/v1.1.2/docs/RELEASE_QA.md); macOS/Safari, physical speakers/projectors and Word GUI are not certified by Windows browser or automated checks.
