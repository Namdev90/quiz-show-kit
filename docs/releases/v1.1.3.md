# Quiz Show Kit v1.1.3

This maintenance release fixes three verified reliability problems without changing question content or scoring rules.

- A paused session stays paused when the host cancels an answer lock or changes into/out of teacher consultation. That includes interruption pauses and restored checkpoints. The original remaining answer or entry time is retained until explicit Resume.
- Literal strings such as `__ENGINE__` or `__CONFIG__` in a quiz no longer collide with the compiler's template replacements. Template components are checked on the original template and substituted once; inserted text is never processed as another placeholder.
- The locked development-only undici dependency moves from 8.11.2 to 8.12.4. The audit used for this release reports no known npm dependency vulnerabilities. This does not represent a security certification of the whole application or its vendored runtime assets.

CI now tests Node.js 22.22.2 and 24 and checks that rebuilt quiz/launcher artifacts exactly match the committed copies. Development requires a jsdom-supported Node version; ordinary builds remain dependency-free.

The current BioVista HTML and launcher are regenerated. Educational content, IDs, stable answer identities, scoring/timing rules, reviewed evidence, DOCX bank and original archived files remain unchanged. The compatible BioVista checkpoint profile is retained; continue an ongoing event in its original file and rehearse upgrades before use.

See [actual checks and limits](../RELEASE_QA.md).
