# Quiz Show Kit v1.1.1

**Try the BioVista Feature Showcase Quiz** downloads the self-contained `BioVista_Quiz_Public_Example.html`. Save it and open it locally. Its supported compatible **Apex** profile enables shuffle, discussion, paired difficulty, alternating round starters, all statistics, revision reports, the supplied character and rich presentation. Settings remain visible and read-only. Apex names this example profile, not a new engine tier or preset.

Normal quizzes remain configurable. Reusable settings exclude the showcase lock; remove `showcase: true` in a separate full configuration when adapting the example. All original question meanings, answers and scoring, the 41-card inventory and the immutable historical archive are preserved. Only DEMO has newly checked evidence and four option rationales; the other 40 inherited cards retain their disclosed evidence gaps. See the [requirements audit](../SHOWCASE_AUDIT.md).

GitHub is the public destination. The confirmed quiz GitHub Pages launcher and preview were unpublished with source/configuration preserved; no replacement hosting was created. The source ZIP retains the useful local launcher, editable DOCX, reusable settings, quality review, tests, notices and historical archive. The retired maker is not restored.

The shared engine now follows live system reduced-motion changes without resetting the coin toss or scores, visibly explains its effective mode, and uses native browser animation fallbacks if GSAP is unavailable. Optional character response tilts the supplied PNG toward the pointer and adds gentle idle motion without changing the artwork or recording coordinates.

This release follows the already published v1.1.0 without modifying its tag or attachments. It retains the four PR #5 safeguards and the release retry/stable-version fixes from PR #7. The release manifest identifies the exact source commit/tree and SHA-256 of every artifact; verify downloads with the checksum file.

Current local and browser checks are recorded in [Release QA](../RELEASE_QA.md). Windows coverage uses the installed Chrome and Edge browsers headlessly with actual local files, UI interactions, rendering and disabled network. It does not establish manual desktop interaction, macOS/Safari, physical speakers, pronunciation, projector/extended-display quality or Word GUI behavior. Optional narration depends on installed local voices or supplied recordings; the included A-D/selection clips remain offline fallbacks. No unsupported/rejected feature, new scientific claim, invented asset or broader reuse license is added.
